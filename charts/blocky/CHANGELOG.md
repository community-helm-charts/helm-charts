# Changelog

## 1.0.0

- Initial Blocky chart.
- Serve DNS-over-HTTPS over plain HTTP for TLS-terminating Ingress controllers.
- Discover the Kubernetes DNS upstream from the Pod resolver or use explicit upstreams.
- Add built-in Blocky DNS liveness/startup probes and a real HTTP DoH readiness query.
- Support optional TLS-terminating Ingress resources.
